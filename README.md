# 在线卡卡颂（Demo v0.3）

单文件 HTML，双人联机拼图对战（非官方同人实现，美术原创）。

访问 `https://Neom987.github.io/car--/`

## 玩法
- 一人「创建房间」，把房间号或邀请链接发给对方；对方输入后自动开局（房主为红方，先手）
- 也可以用「同屏双人」在同一设备上轮流测试
- 操作：点亮起的格子放置地块，R 旋转，点圆圈放随从，拖拽平移，滚轮/双指缩放

## 已实现 / 待做
