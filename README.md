# 在线卡卡颂

单文件 HTML 的双人卡卡颂对战（非官方同人实现）。所有像素美术均由代码程序化绘制，不依赖图片素材。

在线游玩：`https://Neom987.github.io/car--/`

## 玩法
- 同屏双人：一台设备轮流操作。
- 联机对战：一人「创建房间」，把房间号或邀请链接发给对方；对方输入后自动开局。
- 操作：点亮起的格子放置地块，R 旋转，点圆圈放随从；拖拽平移，滚轮/双指缩放，「回到中心」一键复位视角。

## 已实现
- 完整基础规则：72 块地块、边缘匹配、道路/城市/修道院计分、盾牌、随从占用、农夫田地计分（固定开启）、终局结算。
- 14 个扩展包，大厅内可单独开关：河流、客栈与大教堂、修道院院长、商人与建筑师、飞行器、渡口、金矿、法师与女巫、麦田怪圈、节日、幽灵、瞭望塔、水果树、桥梁城堡与集市。
- 联机：PeerJS 同种子 + 动作转发，断线重连、房间邀请链接。
- 结算演出：吸血鬼幸存者风格分数结算——逐波冲击波、速度线、连锁计数、宝石飞入分数条、逐格飘分、屏幕闪白与震屏、终局礼花与飘金币。
- 桥梁：每回合最多架设一座，在刚放置或上下左右相邻的地块上，把两段彼此独立的道路连起来，连通后立即结算。
- 城堡：刚完成的两块小城可改建成城堡——本次不计分、留一名守卫驻守；之后相邻的城市/道路/修道院完成时，自动按该要素基础分结算，守卫与城堡标记返还；终局城堡不计分。
- 集市：集市地块结算后，翻开牌堆中最多三块可放置地块，双方轮流挑选，再各自追加放置一次（正常放随从并计分），剩余地块弃置。
- 对局数据统计、地块图鉴（含剩余数量）。
- 棋子造型：经典小人 / 职业形象 / 史努比三套，随时切换。史努比为 17 列像素矩阵绘制，黑边白身，围巾取玩家色；院长戴金色主教冠、挂十字项链、持权杖，建筑师戴安全帽和圆眼镜、背蓝图卷，幽灵是同色系床单幽灵（下垂波浪下摆），猪保持原造型。
- 圣诞 / 冬季皮肤：一键切换。动态夜景画布逐帧绘制 480×270 像素雪村：抖动星空与闪烁星辰、月亮呼吸月晕、极光、流星、偶尔飞过的圣诞老人雪橇、亮窗小屋与炊烟、路灯、彩灯圣诞树、雪人与树下礼物；操作栏挂松枝彩带、串灯与花环，侧栏换成深松绿卷轴，经典小人戴圣诞帽，大教堂换雪顶，全屏多层雪花随风飘落。尊重「减少动态效果」设置（切换为静帧）。纯代码绘制，不依赖图片素材。
- 智能视角：自动适配棋盘留白；放置地块后轻微推近并跟随新地块。手动缩放/拖拽后保留玩家视角，新地块在视野外时只做最小平移，不抢镜头。
- 程序化背景音乐：D 多利亚调式的南法游吟室内乐——轮擦琴持续低音、拨弦萨泰里琴主旋律、B 段肖姆管与平行声部、框鼓和铃鼓，32 小节循环；冬季自动换成冰质泛音与风床。设置内可单独开关，首次点击后启动，切到后台自动暂停。

## 部署到 GitHub Pages
1. 仓库根目录放 `index.html`。
2. Settings → Pages → Source 选 `Deploy from a branch`，分支 `main`，目录 `/ (root)`。
3. 几分钟后访问 `https://<你的用户名>.github.io/<仓库名>/`。
